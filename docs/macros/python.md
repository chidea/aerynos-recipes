# python macros

| Macro             | Description                                              |
| ----------------- | -------------------------------------------------------- |
| `%python_setup`   | Run `python setup` and build with default options        |
| `%python_install` | Install the python package to the destination directory  |
| `%pyproject_build`| Build a wheel for PEP 517 projects                       |
| `%pyproject_install` | Install the wheel to the destination directory         |
| `%python_compile` | Compile `.pyc` bytecode from stray `.py` files in the install dir |
