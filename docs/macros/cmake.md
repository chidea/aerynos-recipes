# cmake macros

| Macro          | Description                                  |
| -------------- | -------------------------------------------- |
| `%cmake`       | Run cmake with default options in a subdirectory |
| `%cmake_make`  | Run cmake using make as the build server     |
| `%cmake_unity` | Run cmake with unity build enabled           |
| `%cmake_build` | Build the cmake project                      |
| `%cmake_install` | Install the build to the destination dir    |
| `%cmake_test`  | Run the test suite with ctest                |
