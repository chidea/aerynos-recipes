# qt-kde macros

| Macro                 | Description                                              |
| --------------------- | -------------------------------------------------------- |
| `%qmake_qt5`          | Invoke Qt5 with the correct default values               |
| `%cmake_qt6`          | cmake with default options for Qt6 builds                |
| `%cmake_kf6`          | cmake with defaults for KF6/Qt6 (KDE Frameworks, Plasma, KDE Gear) |
| `%qt_user_facing_links` | Setup user-facing binaries (**DEPRECATED**)            |
