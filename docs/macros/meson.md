# meson macros

| Macro          | Description                                  |
| -------------- | -------------------------------------------- |
| `%meson`       | Run meson with default options in a subdirectory |
| `%meson_unity` | Run meson with unity build enabled           |
| `%meson_build` | Build the meson project                      |
| `%meson_install` | Install the build to the destination dir    |
| `%meson_test`  | Run `meson test`                             |
