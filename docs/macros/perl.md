# perl macros

| Macro                | Description                                                     |
| -------------------- | --------------------------------------------------------------- |
| `%perl_setup`        | Create a Makefile with ExtUtils::MakeMaker (use with `%make`/`%make_install`) |
| `%perl_module_setup` | Create a build script with Module::Build                        |
| `%perl_module_build` | Build a perl module with Module::Build                          |
| `%perl_module_install`| Install a perl module with Module::Build                        |
